aws-advance-arch (Slotta practice) - Cost for ONE 3-hour deploy -> test -> destroy run
=====================================================================================
Region: us-east-1. On-demand list prices (Oct 2026). Track A = no custom domain.
The deployment guide creates the FREE resources first and the HOURLY ones
(NAT Gateway, ALB) last, so the paid clock only runs ~2 hours. The numbers
below assume a full 3 hours anyway (worst case).

HOURLY-BILLED (the ones that matter - delete these first at teardown)
---------------------------------------------------------------------
NAT Gateway        $0.045/h x 3 h                                  $0.14
  + data processed $0.045/GB x ~0.5 GB (image pulls, JWKS, egress) $0.02
  + its public IPv4 (Elastic IP) $0.005/h x 3 h                    $0.02
ALB                $0.0225/h x 3 h                                 $0.07
  + LCUs (light testing) ~$0.008/h x 3 h                           $0.02
  + 2 public IPv4 addresses (one per AZ) $0.005/h x 2 x 3 h        $0.03
ECS Fargate        0.25 vCPU + 0.5 GB, 1 task, 3 h                 $0.04
  ($0.04048/vCPU-h, $0.004445/GB-h; private subnet = no public IP charge)
                                                       Subtotal   ~$0.34

USAGE-BASED (cents or zero at this scale)
-----------------------------------------
Amplify Hosting    ~4 builds x ~4 min x $0.01/min (if outside free build minutes)  $0.00-0.16
                   SSR compute + requests + storage for a few page loads           ~$0.00
CodeBuild          general1.small $0.005/min x ~3 builds x 3 min   $0.05 (100 free min/month may cover it)
CodePipeline V2    $0.002/action-minute, ~10 min                   $0.02 (100 free min/month may cover it)
ECR                ~0.2 GB image, a few hours of storage           <$0.01
CloudWatch         logs + Container Insights for 3 h               ~$0.02
DynamoDB           on-demand, a handful of reads/writes            ~$0.00
Cognito            Essentials tier, first 10,000 MAU free          $0.00
SQS / S3           a few requests                                   ~$0.00
                                                       Subtotal   ~$0.09-0.25

PRORATED MONTHLY FEES (billed only for the hours they exist)
------------------------------------------------------------
KMS key            $1/month -> ~3 h                                ~$0.01  (no charge while pending deletion)
Secrets Manager    $0.40/secret/month -> ~3 h                      ~$0.01
                                                       Subtotal   ~$0.02

TOTAL, Track A (3 hours, worst case) ................  ~$0.45 - $0.65
  Budget alert at $5 so a forgotten resource can't surprise you.

TRACK B EXTRAS (custom domain + HTTPS, the real Slotta shape)
-------------------------------------------------------------
Route 53 hosted zone  $0.50/month, but a zone DELETED WITHIN 12 HOURS of creation is not charged -> $0.00
DNS queries           ~$0.00
ACM certificate       free
Domain registration   only if you don't already own one: ~$13-15/year (.com) - NOT refundable
WAF (optional)        $5/web ACL/month + $1/rule/month, prorated -> ~$0.03 for 3 h

IF YOU FORGET TO TEAR DOWN (per day)
-------------------------------------
NAT Gateway ~$1.20 + ALB ~$0.80 (incl. IPv4) + Fargate ~$0.30 + leftover Elastic IP $0.12
=> about $2.40/day, ~$75/month. Delete the NAT Gateway, its Elastic IP and the ALB first.
